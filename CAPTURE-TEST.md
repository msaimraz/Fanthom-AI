## 2. Capture Mechanism & Configuration
- **Hook Configuration File**: [`.agents/hooks.json`](file:///c:/Work/git/Fanthom-AI/.agents/hooks.json)
- **Capture Script**: [`.agents/capture.py`](file:///c:/Work/git/Fanthom-AI/.agents/capture.py)
- **Mechanism Details**:
  - The `Stop` lifecycle hook fires automatically when the agent execution loop terminates at the end of each turn.
  - Antigravity passes execution context via JSON on `stdin`, containing `conversationId`, `workspacePaths`, `transcriptPath`, and `modelName`.
  - The capture script accesses the full session transcript (`transcript_full.jsonl`) generated by Antigravity under `~/.gemini/antigravity/brain/<conversationId>/.system_generated/logs/`.
  - It extracts each exchange without thinking tags, tool invocations, or intermediate steps:
    - User prompt verbatim in full (extracted from `<USER_REQUEST>...</USER_REQUEST>`).
    - Final model response verbatim in full.
    - UTC ISO timestamp.
    - Model name (`gemini-3.8-flash-high`).
  - Writes the formatted session log to `.agent-logs/YYYY-MM-DD_HH-MM-SS_<session-id>.md`.
  - Returns `{"decision": "allow"}` on `stdout` according to the Antigravity lifecycle hook contract.

## 3. Log Storage
- Captures are written directly to `.agent-logs/` in the repository root.
- `.agent-logs/` is explicitly tracked in git and NOT added to `.gitignore`.

## 5. Implementation Notes & Troubleshooting
- Direct reading of global `~/.gemini/config/config.json` was blocked by system protection boundary, confirming that repository-scoped `.agents/hooks.json` is the correct, team-shareable, and version-controlled customization mechanism.
- Handled Windows command invocation semantics (`cmd /c` running `python capture.py` within `.agents` working directory).
- Added a non-blocking stdin timeout to `capture.py` to prevent Windows pipe stalls when invoked in headless subshells.
- Resolved full transcripts via `transcript_full.jsonl` rather than `transcript.jsonl` to ensure zero truncation of user prompts and model responses.
